# Implementation Phases

1. Foundation: repository, environment, Docker, backend, frontend, NGINX.
2. Accounts and scoped RBAC.
3. Four-validator Besu QBFT network.
4. Contracts and authorization tests.
5. Central Web3 transaction service, event indexer, reconciliation.
6. DID onboarding, challenge verification, lifecycle, rotation.
7. Encrypted digital/physical asset records and NFT minting.
8. Controlled transfer state machine.
9. Audit, alerts, explorer, health, and safe security demos.
10. Role-aware frontend and complete E2E coverage.
11. Clean-environment verification and hardening.

Each phase must leave runnable tests and accurate status documentation.
